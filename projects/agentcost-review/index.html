Cheaper is not
always feasible.

When review takes longer, cost rises. But the moment another option becomes cheaper is not necessarily the moment you can switch to it.

Illustrative planning assumptions. This annual case uses 20,000 contracts, 2,400 reviewer hours, a 35% exception share and $90 per reviewer hour. It is distinct from the portfolio's per-contract illustrative calculator. No measured savings, staffing requirement or accepted-error guarantee is implied.

The recommendation changes at the capacity boundary

18.23 minutes

Exception review time at which triage ties the theoretical review-all economic cost. Review-all already exceeds capacity, so it does not become an acceptable fallback here.

19.71 minutes

Exception review time at which triage reaches its own annual capacity limit. Above it, no option passes the declared capacity and risk gates.

Decision: request a bounded evaluation before funding deployment. If no option is feasible, hold or explicitly revise capacity, scope and assumptions. Do not select the cheapest failing option.

Five acceptance checks

  1. Reconcile the base case with the existing activity-based model.
  2. Check both sides of economic equality without approving an infeasible alternative.
  3. Check both sides of the capacity limit.
  4. Retain the risk veto even when review time is zero.
  5. Keep valued capacity separate from cash outlay.

The boundary equations use Decimal arithmetic and are compared with the existing cost engine. These are finite technical checks, not production calibration or business sign-off.

Limits that change the decision

This varies review time alone. It does not model how review effort changes actual risk. Declared incident rates are assumptions, annual averages do not establish peak staffing or queue service levels, and historical clause correctness does not measure legal-loss severity.

A real evaluation would separately measure reviewer time, workload mix and accepted-error risk before committing integration costs. Proposed owners and review gates are not fabricated stakeholder approvals.
