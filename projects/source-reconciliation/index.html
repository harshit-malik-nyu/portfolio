2. Understand what changes the answer

The missing denominator

Start from eligible completed orders and left join the delivered events. Starting from events alone would hide orders with no event.

The delivery cutoff

A transaction received after the declared cutoff cannot repair that earlier snapshot. Compare the paired earlier and later snapshots to see the same delivery move from missing to reconciled.

The maturity trade-off

Grace time allows delivery latency. Increasing it also removes recent orders from the eligible population. Pending is shown separately; it is never disguised as a successful reconciliation.

Expected cents must equal matched + missing + exception source cents in each currency. A duplicated order counts once in source exception value. USD and EUR are never combined or converted.

What this does not prove

The supplied ledger may itself be incomplete. The declared watermark, authority and grace period are assumptions, not authenticated facts. A historical replay requires an actual historical source snapshot. Matching does not establish accounting revenue, production completeness, personal unaided mastery or rollout readiness.

Refunds, partial captures, changing order versions, multiple payments and real production integration are outside this contract. The examples and finite tests are not exhaustive certification.
